# Weather Detection Website

A simple and responsive web application to check real-time weather information for any city using the WeatherAPI.

## Features
- Search weather for any city
- Display temperature, condition, humidity, wind speed, etc.
- User-friendly and responsive interface
- Fully frontend, deployed on GitHub Pages

## Technologies Used
- HTML
- CSS
- JavaScript
- WeatherAPI

## Live Demo
[https://gopeshverma.github.io/weather-app/](https://gopeshverma.github.io/weather-app/)

## How to Use
1. Open the Live Demo link in any browser.
2. Enter the city name in the search box.
3. Press Enter or click the search button.
4. See the current weather details instantly.
